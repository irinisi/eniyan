Лог изменений — июль 2026
Мини-апп
Редактирование задач
Теперь при нажатии на задачу открывается форма редактирования, а не просто просмотр. Можно изменить название, описание, исполнителя, срок, проект, приоритет и статус. Там же кнопка удаления задачи.

Формат даты
Даты отображаются в формате ДД.ММ.ГГГГ вместо YYYY-MM-DD.

Цвета приоритетов

HIGH — красный
MEDIUM — синий
LOW — серый
Цвета столбцов канбана
Каждый столбец получил цветную полоску сверху: серая (К выполнению), синяя (В работе), жёлтая (На проверке), зелёная (Готово).

Смена исполнителя
В форме редактирования задачи поле исполнителя с автодополнением — подставляет имена из существующих задач.

Аватарки исполнителей
У каждого исполнителя свой цвет аватарки, стабильный и уникальный — вычисляется из имени.

Бот
Команды и подсказки
Бот показывает список команд при вводе /. Добавлено приветствие с описанием всех команд.

Привязка пользователя
Команда /iam @username — связывает Telegram-аккаунт с именем исполнителя из задач. После этого /tasks показывает только твои задачи.

Мои задачи / Все задачи
/tasks — только активные задачи текущего пользователя. /alltasks — все открытые задачи команды.

Кнопки быстрого доступа
Клавиатура с кнопками: Мои задачи, Новая задача, Все задачи, Поиск.

Ежедневный дайджест
Каждый день в 12:00 (МСК) бот присылает сообщение с задачами на сегодня и просроченными задачами.
